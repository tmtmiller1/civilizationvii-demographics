# docs

Public-facing copy for the Demographics mod. (Internal planning / dev-research
notes are archived outside the repo, not kept here.)

## Subfolders

- screenshots  -  In-game captures used by the repository README gallery (33 views, 1920 px JPEG).
- steam-screenshots  -  The subset uploaded to the Steam Workshop listing, copied and numbered in upload order.
- plans  -  Design plans for larger features (hub reorganization, rankings, labels, trade routes).

## Files

- steam-workshop-description.md  -  Stores the fuller Steam Workshop listing copy.
- steam-workshop-description-short.md  -  Stores the compact Steam Workshop listing copy.
- steam-workshop-description.txt / -short.txt  -  The same copy as plain .txt, to paste into the Workshop editor.
- BACKLOG.md  -  Open items and follow-ups, newest first.
- workshop-preview.png / workshop-preview.svg  -  Steam Workshop preview art.
- new-graphs-since-steam-2.4.5.md  -  Summary of graphs added since the 2.4.5 Workshop release.
- commit-ready-hardening-notes-2026-06-26.md  -  Hardening notes from the June 2026 pre-release review.
- hardening-2026-09-22.md  -  The 2.7.3 hardening pass: audit classes, what changed, what was watched, release gates.
- civ7-storage-bug.md  -  The game storage bug behind the Hall of Fame notice and what Repair mod storage does.
