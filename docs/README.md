# docs

Pictures and player-facing text for the Demographics mod. Working notes and plans are kept outside the repository.

## Folders

- screenshots: the in-game captures in the repository README's gallery (38 views, 1920 px JPEG).
- steam-screenshots: the subset uploaded to the Steam Workshop page, copied and numbered in upload order.

## Files

- civ7-storage-bug.md: the Civilization VII storage bug behind the Hall of Fame notice, and what Repair mod storage
  does.
- steam-workshop-description.md: the full Steam Workshop page text, in Steam's BBCode.
- steam-workshop-description-short.md: a shorter version of the same page.
- steam-workshop-description.txt / -short.txt: the same text, identical to the .md files, to paste into the Workshop
  editor.
- workshop-preview.png / workshop-preview.svg: the mod icon and Workshop preview (the PNG is rendered from the SVG).
